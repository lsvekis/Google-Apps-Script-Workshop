# Hands-On AI: 30 Google Workspace Apps

Run WorkshopGenerator.js in a standalone Apps Script project: generateWorkshop once, then generateNextBatch five times. Open the logged Drive folder and matching spreadsheet. Each lesson is independent; copy its Code.js into its own bound Apps Script project as Code.gs. Never paste all 30 into one project. AI lessons require an API key and supported model ID; use synthetic data and review AI outputs. No app sends email automatically. Reference solutions are syntax-checked, not live-tested.

## Publish
Create an empty GitHub repository, then from this folder run `git init`, `git add .`, `git commit -m "Add 30 workshop apps"`, `git branch -M main`, `git remote add origin YOUR_REPOSITORY_URL`, `git push -u origin main`. Never commit API keys.
